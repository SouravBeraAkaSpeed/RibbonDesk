# Project guidance

This repository is an entry for the Convex All Gas Hackathon.

- Treat `hackathon.md` as a public, judge-facing build log.
- After each meaningful implementation or verification session, update it from
  repository evidence using the installed `convex-hackathon-skill` workflow.
- Write entries in first person as the builder: concise, factual, and focused on
  shipped behavior before implementation detail.
- Keep `HACKATHON_REQUIREMENTS.md` as the working compliance checklist and
  re-verify live event pages before registration, deployment, and submission.
- Never put secrets, tokens, deployment keys, inbox addresses, personal data,
  or private database records in either file.
